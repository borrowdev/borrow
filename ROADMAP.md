## Borrow PrettyHash
**Progressive image rendering but pretty.**
  - [ ] Progressive Edges: Stream and reveal more edges of the image as it loads (extracted using edge detection algorithms such as canny or lightweight AI models).
  - [ ] Progressive Depth: Stream and reveal depth masks of the image as it loads (can start from front to back, back to front, random, smallest file size first (default), etc).
  - [ ] Progressive Noise: Start from noise and stream the image denoising process.
  - [ ] Progressive Blur: Stream the deblurring process with ThumbHash.
  - [ ] Progressive Shapes: Stream small sections of the image all divided by the same pattern (user-defined, but there are presets such as squares).
  - [ ] Progressive Paint: Stream left-to-right or top-to-bottom smooth painting effect (with mask reveal).
  - [ ] Progressive Bit Depth: Stream the image as 1bit (black/white), then as 8-bit grayscale, and then as full color.
  - [ ] Progressive pixel art
  - [ ] Progressive ASCII art
